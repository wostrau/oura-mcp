# Privacy Policy

Last updated: September 28, 2026

## Overview

This application is a personal, non-commercial integration used by the application owner to access and analyze their own Oura data.
The application is not offered as a public service and is not intended for use by other users.

## Data Access

The application may access Oura data authorized by the application owner through Oura OAuth, including data related to:
- sleep
- readiness and daily metrics
- activity
- heart rate
- workouts
- sessions
- SpO2
- stress

Only data explicitly authorized through Oura OAuth scopes is accessed.

## Purpose

Oura data is accessed solely for personal analysis of sleep, recovery, physical activity, training load, stress, and related health and wellness metrics.

## Data Storage

OAuth credentials and authentication tokens are stored locally on the application owner's device.
The application does not operate a separate external database for storing Oura data.

## Data Sharing

The application does not sell Oura data.
Data may be processed by software and AI tools explicitly used by the application owner for personal analysis.
No Oura data is intentionally made publicly available through this repository.

## Third-Party Services

Access to Oura data is provided through Oura's services and is subject to Oura's applicable privacy policies, terms, and developer agreements.
When the application owner chooses to process data using a third-party tool, that processing may also be subject to the privacy terms of that service.

## Security

Authentication credentials, client secrets, access tokens, and refresh tokens are not intended to be committed to this public repository.
Reasonable measures are taken to keep authentication credentials private and stored locally.

## Changes

This Privacy Policy may be updated if the application's functionality or data-processing practices change.
